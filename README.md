# Turbo Ridge

A lightweight, single-file HTML5 Canvas hill-climb game. No npm install, build step, or external library is required.

## Run locally
Open `index.html` in a modern browser. On mobile, open the page in Chrome.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for GitHub Pages to finish publishing. The site URL will appear on that page.

## Controls
- Hold **GAS** to accelerate.
- Hold **REV** to brake/reverse.
- Keyboard: Right / D = gas; Left / A = brake.

## Notes
This repository currently contains a 2D Canvas prototype, not a Unity 3D project. The rewards/cashout screen is a visual demo only; it does not connect to a real ad network, wallet, UPI, or payment processor.
